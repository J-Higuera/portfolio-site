Resilience & recovery
Pi reboot
Auto-recovers
Gateway auto-starts via systemd with user linger enabled. Tailscale Serve persists. MSI node reconnects via 10-second retry loop.
Internet outage
Auto-recovers
Gateway keeps running locally on the Pi. Tailscale reconnects automatically when internet returns. Node retries connection every 10 seconds.
Gateway crash
Auto-recovers
Systemd detects the crash and restarts the gateway service. Node detects the disconnect and retries until the gateway is back online.
