Resilience & recovery
Pi reboot
Auto-recovers
Gateway + dashboard auto-start via systemd with user linger. Tailscale Serve persists. MSI node reconnects via 10-second retry loop.
Internet outage
Auto-recovers
Gateway keeps running locally on the Pi. Tailscale reconnects automatically when internet returns. Node retries every 10 seconds.
Gateway crash
Auto-recovers
Systemd detects the crash and restarts the gateway. Node detects disconnect and retries until gateway is back online.
